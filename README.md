# City Care Hospital

A simple hospital website built with **HTML and CSS**. It presents the hospital, its departments, doctors, and appointment section in a clean and straightforward layout.

## Project Files

### `index.html`
This is the main file of the website. It contains:

- Emergency hotline
- Navigation bar with Home, About Us, Services, Doctors, and Appointment links
- Hero section with the hospital introduction and Learn More button
- About Us section
- Medical Departments section
- Meet Our Doctors section
- Appointment booking form
- Hospital information
- Footer with quick links and copyright information

### `style.css`
This file controls the complete styling of the website, including:

- Colors, spacing, and typography
- Navigation bar and hero section
- Buttons and links
- Medical department cards
- Doctor cards and images
- Appointment form and hospital information
- Footer layout

### `images/`
This folder contains the visual assets used throughout the website:

- **Hospital Logo** — used in the navigation bar
- **Hero Image** — used in the main hero section
- **Department Images** — used for the Cardiology, Dental Care, Eye Care, and General Clinic sections
- **Doctor Images** — used in the Meet Our Doctors section

## Technologies Used

- HTML
- CSS

Open `index.html` in a browser to view the website.
